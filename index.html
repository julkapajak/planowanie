macOS

Apple Silicon i Intel, macOS 11 lub nowszy

Pobierz dla Maca (.dmg)
Jak zainstalować?
  1. Otwórz pobrany plik i przeciągnij Planowanie do folderu Aplikacje.
  2. Uruchom aplikację. Jeśli macOS ostrzeże, że nie może jej sprawdzić, wejdź w Ustawienia systemowe → Prywatność i ochrona i kliknij „Otwórz mimo to”.
🐧

Linux

Każda dystrybucja (AppImage) albo Ubuntu / Debian (.deb)

Pobierz AppImage Pobierz .deb
Jak zainstalować?
  1. AppImage: kliknij plik prawym przyciskiem → Właściwości → „Zezwól na uruchamianie”, potem otwórz.
  2. .deb: sudo apt install ./Planowanie-linux-amd64.deb
